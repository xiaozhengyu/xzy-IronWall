# Design: 伤害数字缩放

## Rendering Rule

- `DamageNumbers.draw()` 继续使用 `grain` 计算数字在场景中的屏幕位置。
- 字模基础倍数固定为当前默认视野下的可读整数倍，不再由当前 `grain` 动态放大或缩小。
- 现有样式倍率保留：升级、暴击、首领、回血/回蓝分别继续使用当前相对倍率。
- 只有带有同一 `groupKey` 的战斗命中才参与合并；同一目标在 `0.18s` 窗口内累加数值并复用已有飘字。
- 普通伤害达到中等密度后按序列降采样，达到极高密度后直接丢弃新的普通数字；暴击、首领、回复和升级数字不参与降采样。
- 受击数字使用独立的高位锚点（比人物头顶再高约 `9` 个世界单位），击飞反方向偏移从 `7` 调整到 `11`；玩家自身的回复、回蓝、增益和升级数字继续使用调用方传入的锚点。

## Player Settings

- `Profile.settings.combatText` 持有 `damage`、`heal`、`mana`、`buff`、`level` 五个布尔开关，默认全部开启。
- 旧存档加载时对缺失字段补 `true`，不改变已有语言、音效和音乐设置。
- 五类开关只出现在 ESC 暂停/结算页面的设置区，复用现有两态 chip 样式；不扩展备战页顶栏。
- 关闭某类后，`Battle.damageNumbers` 立即删除该类已有事件，并拒绝后续同类事件；伤害和资源模拟仍照常进行。

## Runtime Flow

1. Battle 按现有流程生成伤害数字事件，并将受击敌人作为 `groupKey`。
2. DamageNumbers 先查找同一目标在合并窗口内的已有事件；命中时累加值并延长已有事件，不创建新数字。
3. 没有可合并事件时，普通数字按当前活跃数量执行密度降采样，关键样式直接进入池子。
4. Battle 按显示设置过滤五类事件；关闭设置时清理对应事件。
5. Scene 传入当前相机位置和 `grain`；DamageNumbers 用 `grain` 投影位置和上飘高度，用固定基础倍数绘制字模。
6. PixelSurface 继续按原有最近邻规则放大整帧。

## Module Impact

- `src/effects/damageNumbers.ts`: 固定基础字模倍数，增加目标合并、密度降采样和关键样式优先级。
- `src/game/battle.ts`: 为敌人伤害数字传入目标分组键。
- `src/game/profile.ts`: 增加五类战斗信息显示设置和旧存档默认补齐。
- `src/ui/summary.ts`, `src/main.ts`: 增加 ESC 设置行、持久化接线和 Battle 实时同步。
- `src/ui/text/hudText.types.ts`, `hudText.zh-CN.ts`, `hudText.en.ts`: 增加五类设置文案。
- `docs/spec/damage-number-scale/`: 记录需求、设计和验证方式。
- `docs/decisions/AI_CHANGELOG.md`: 记录本次渲染逻辑变化。

## Edge Cases

- `grain` 在最小和最大边界时，数字仍保持基础可读尺寸。
- 不同样式不能绕过基础倍数规则，否则放大视野时会出现只有特殊数字过大的情况。
- 同一目标持续受击时，合并数字不会因为每一击重新淡入而闪烁；连续命中只延长可见时间。
- 飘字池满时，关键样式可以淘汰普通伤害事件，但不会淘汰另一个关键样式。
- 关闭显示设置不会阻止实际伤害、回复、消耗、升级或增益，只影响战斗飘字。
- 关闭某类后重新开启只影响新生成的数字，不恢复关闭期间已清理的旧数字。
- 数字位置仍随相机缩放变化，不能把固定字号误用为固定世界尺寸。

## Non-Goals

不调整数字池容量、漂移、碰撞遮挡层级、伤害值取整或任何战斗模拟逻辑。合并和显示开关只改变显示事件，不改变实际伤害累计。
