# Feature: 伤害数字缩放

## Player Problem

滚轮放大视野时，伤害数字会随相机 `grain` 一起放大。数字覆盖范围明显增加，敌群密集时会遮挡战场和攻击反馈。

## Desired Outcome

伤害数字在不同视野缩放下保持稳定、可读的屏幕尺寸，并在密集战斗中减少同时存在的飘字数量。玩家还可以独立关闭伤害、回血、回蓝、增益和升级等信息。

## In Scope

- 解耦伤害数字字模尺寸与视野 `grain`。
- 合并同一目标短时间内的多次伤害，保留合并后的总伤害值。
- 在飘字密度过高时减少普通伤害数字，优先保留暴击、首领和回复类反馈。
- 将伤害数字的起点抬高，并沿击飞反方向增加偏移，让数字离受击人物更远。
- 在 ESC 暂停/结算页面提供伤害、回血、回蓝、增益和升级五类独立开关。
- 将显示开关持久化到现有玩家存档，关闭时立即清理对应的场上数字。
- 保留数字位置、上飘速度、颜色、描边和不同类型的相对字号差异。

## Out of Scope

- 不改变伤害计算、暴击概率、技能命中频率或实际战斗事件。
- 不改变场景中角色、敌人和特效的缩放规则。
- 不在备战页顶栏增加新的设置组，避免顶栏拥挤。
- 不改变技能演示卡片中的示例飘字。

## Acceptance Criteria

- [ ] 滚轮放大视野时，普通伤害数字不再随 `grain` 变大并遮挡敌群。
- [ ] 滚轮缩小时，数字不缩小到难以辨认的程度。
- [ ] 暴击、首领、回血/回蓝和升级数字仍保持相对字号差异。
- [ ] 默认缩放下伤害数字的大小和位置保持兼容。
- [ ] 同一敌人在短时间内的多次伤害显示为一个合计值，不连续堆叠多个普通数字。
- [ ] 密集战斗中普通数字会自动降采样，关键反馈仍可见。
- [ ] 伤害数字相对受击人物明显上移并向击飞反方向偏移。
- [ ] 五类显示开关可以独立切换，关闭后对应数字立即消失。
- [ ] 显示开关在刷新页面或重新开始游戏后仍保持上次选择。

## Constraints

- 只调整 `DamageNumbers` 的渲染字号计算；世界坐标到屏幕坐标的换算保持不变。
- 遵循现有像素字模和最近邻渲染规则，基础字号必须为整数像素倍数。
