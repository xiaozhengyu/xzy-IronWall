# Feature: 小地图显示设置

## Player Problem

当前小地图固定在页面右上角，部分玩家希望把它放到左上角，或在战斗中完全隐藏以减少 HUD 占用和视觉干扰。

## Desired Outcome

小地图移动到页面左上角，并提供一个可持久化的显示开关；资源面板继续独立位于右上角。

## In Scope

- 将小地图 HUD 锚定到左上角。
- 删除左上角“按 ESC 暂停”提示，释放小地图旁的空间并减少常驻文字噪音。
- 保持小地图尺寸、内部缩放、玩家/敌人/地标标记逻辑不变。
- 在 ESC 暂停/结算页面增加“小地图”开关。
- 关闭小地图时立即隐藏并停止小地图绘制。
- 将选择保存到现有玩家 Profile，并兼容旧存档。
- 添加中英文设置文案和布局样式。

## Out of Scope

- 不改变资源面板、波次面板、血蓝条和快捷栏的位置。
- 不改变小地图的视野倍率、颜色、标记规则或刷新频率。
- 不在备战页顶栏增加新的设置组。

## Acceptance Criteria

- [ ] 小地图显示在页面左上角，且不遮挡波次面板和资源面板。
- [ ] 左上角不再显示“按 ESC 暂停”提示文字。
- [ ] 资源面板仍显示在页面右上角。
- [ ] 关闭“小地图”后小地图立即消失，重新打开后恢复绘制。
- [ ] 刷新页面或重新进入游戏后，小地图开关保持上次选择。
- [ ] 旧存档缺少新字段时默认显示小地图。

## Constraints

- 复用现有 `Profile` 设置和 ESC 页面两态开关样式。
- 隐藏小地图时跳过 `Minimap.draw()`，避免无效 Canvas 绘制。
