# 游戏音效素材目录

每个文件夹代表一个逻辑音效。文件名随意，可以放多个变体；游戏每次播放时会随机选择一个。
支持小写扩展名 `.ogg`、`.wav`、`.mp3`，加入或替换文件后重新构建即可生效。

## 投放位置

| 文件夹 | 用途 | 建议素材 |
| --- | --- | --- |
| `foot_grass/` | 玩家走在草地上的每次落脚 | 3–6 个变体，80–200ms，近距离布靴/皮靴，尾音短 |
| `battle_hit/` | 普通攻击或技能命中 | 4–8 个变体，60–220ms，只要撞击，不要长挥舞声 |
| `battle_critical/` | 暴击命中 | 2–4 个变体，120–400ms，比普通命中更亮、更重 |
| `pickup/` | 拾取灵石、金币、药或符 | 3–5 个变体，80–300ms，清晰但不要组成长旋律 |
| `level_up/` | 角色升级 | 1–3 个变体，500–1500ms，能穿过战斗声但不要像背景音乐 |
| `boss_enter/` | 首领出场 | 1–3 个变体，700–2000ms，低沉、警示感，不带循环 |

## 统一要求

- 都是一次性播放的 one-shot，不要无缝循环素材。
- 尽量裁掉开头静音；加载器仍会自动跳过少量残留静音。
- 不要烘进明显的室内混响，画面是户外战场。
- 单声道优先；采样率 44.1kHz 或 48kHz。
- 文件夹可以暂时为空，缺少某类素材时游戏会静默跳过，不会报错。
